欢迎使用 DSH-for-Zotero

在 Zotero 里用 DeepSeek Harness 的 Agent 读文献 —— 它能读你的论文全文与划注， 也能改标签、加笔记、建条目。

1它在准备自己的运行时

插件会在 Zotero 数据目录下准备一份独立的 dsh 运行时（独立端口与凭据， 与你桌面版的 Harness 互不干扰）。

首次需要从本机 Harness 提取约 330 MB，大约 10–30 秒。

⚠️ 这段时间会看到一个进度窗口。如果显示「找不到 DeepSeek Harness 安装」， 说明本机没装或装在别处 —— 到 编辑 → 设置 → DSH-for-Zotero 里指定安装目录即可。

2从右键菜单建一个会话

  • 按分类读：在文献库界面右键一个分类 → 新建独立会话。它的工作区就是这个分类，适合"把这几篇对比一下"。
  • 按单篇读：右键一个条目 → 新建会话。工作区就是这篇文献。

会话会作为一个真实的 Zotero 附件挂在库里，双击即可打开继续对话。

3它能改你的文献库，但危险操作要你点确认

  • 改标签、加笔记、加入分类 —— 直接执行，Ctrl+Z 可撤销。
  • 新建条目与删除 —— 会先在会话页顶部出现黄色角标 「有 N 项改动等你确认」，你点确认后才真正执行。
如果自检或问答有问题，设置 → DSH-for-Zotero → 自检 会给出逐项结论， 并可导出到数据目录下的 dsh-for-zotero-selfcheck.txt。
随时可在设置页重新打开这个引导。
